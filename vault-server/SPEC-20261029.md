## 1. 비밀 검사기 (pre-receive)
파일: `~/vault.git/hooks/secret-scan.py`, `~/vault.git/hooks/pre-receive`.
- pre-receive 는 `set -o pipefail` 과 오류 시 거절. ref 마다 유입 커밋 목록을 구한다: 기존 ref 는 `git rev-list old..new`, 신규 ref 는 `git rev-list new --not --all`(단, 루트 커밋 포함). **각 커밋의 변경을 모두 검사**한다: `git diff-tree -r -p --root --no-commit-id <commit>`. 같은 blob(해시)은 한 번만 검사(중복 제거). 하나라도 걸리면 push 전체 거절, 출력에 커밋 짧은 해시·파일·줄·종류만(값 금지).
- `# vault-allow` 인라인 우회 **삭제**. 대신 저장소 루트의 `.vault-scan-allow` 파일(push 되는 트리 기준 `git show <commit>:.vault-scan-allow`)에 한 줄에 경로 glob 하나. 그 경로의 내용 검사만 건너뛴다(파일명 금지 규칙은 유지).
- 패턴: 기존(Anthropic/OpenAI/AWS/GitHub/Google 키, Telegram 토큰, 개인키 블록, 주민등록번호, 키=값 비밀) + **카드번호**(13~16자리, 구분자 `-`/공백 허용, Luhn 검사 통과 시만). **전화번호·주소·계좌는 넣지 않는다**(CEO: 업무 노트 오탐). 키=값 패턴의 단어 뒤 값 최소 길이는 8.
- 바이너리: 이미지(.png .jpg .jpeg .gif .webp .svg) 와 .pdf 는 내용 검사 생략·허용. 그 외 바이너리(diff 가 "Binary files" 로 나오는 것)는 `.vault-scan-allow` 에 없으면 거절("검토되지 않은 바이너리").
- 파일명 금지 규칙은 유지(.env*, *.pem, *.key, *.p12, *.pfx, id_rsa*, id_ed25519*, credentials*.json, *secret*.json/yaml/toml). 경로가 따옴표로 인코딩돼도(한글 경로) 잡히게 `git diff-tree -z` 또는 `-c core.quotepath=false` 사용.
- stdin 스트리밍 유지, 탐지 결과는 최대 50건만 보관.
- 단위 시험 스크립트 `~/vault.git/hooks/test-secret-scan.sh`: 임시 bare+클론을 `mktemp -d` 아래에 만들어(삭제는 하지 않고 경로만 출력) 다음을 확인: (a) 중간 커밋에 비밀을 넣고 다음 커밋에서 지운 2커밋 push → 거절 (b) 깨끗한 push → 통과 (c) `.vault-scan-allow` 에 든 경로의 키=값 → 통과 (d) 한글 파일명 `.env` 류 → 거절 (e) png 추가 → 통과 (f) 미등록 바이너리(.bin) → 거절. 시험용 비밀 문자열은 `EXAMPLE`·`TEST` 가 들어간 가짜만 쓴다.

## 2. 에이전트 쓰기 분리
- `~/vault` 는 **읽기 전용 거울**. 아무도 여기서 편집·커밋하지 않는다. post-receive 는 `git -C ~/vault pull --ff-only` 만 한다(그래프 실행 **제거**). ff-only 실패 시 로그 + `~/bin/notify`.
- 새 클론 `~/vault-agent` (`git clone ~/vault.git ~/vault-agent`). 에이전트는 여기 `00-inbox/agent/` 에만 쓴다.
- 도우미 `~/bin/vault-note`: 사용법 `vault-note <파일명.md> < 내용` 또는 `vault-note <파일명.md> <내용파일>`. 동작: `~/vault-agent` 에서 `git pull --rebase --quiet origin main` → `00-inbox/agent/<파일명>` 에 쓰기(frontmatter 없으면 title/type: inbox/updated: 오늘 자동 삽입) → `git add` 해당 파일만 → commit(메시지 `agent: <파일명>`) → push. push 가 non-fast-forward 로 거절되면 `pull --rebase` 후 1회 재시도. 그래도 실패하면 종료코드 1 + 메시지. 비밀 검사 거절이면 로컬 커밋을 `git reset --soft origin/main` 으로 되돌리고 파일은 남긴 채 메시지 출력(값 미표시). 파일명은 `00-inbox/agent/` 밖으로 못 나가게 `..`·`/` 거부.
- `~/vault-agent/.git/hooks/pre-commit` 에 같은 검사기 연결(`git diff --cached | python3 -I ~/vault.git/hooks/secret-scan.py`). `~/vault/.git/hooks/pre-commit` 은 제거(거울은 커밋 안 함).
- `~/vault/CLAUDE.md` 의 "## Sync Rules" 절을 다음 뜻으로 고친다: `~/vault` 는 읽기 전용 거울, 쓰기는 `vault-note` 로만, 쓰기 가능 경로는 `00-inbox/agent/` 만, 비밀·개인정보 금지(서버 거절).
